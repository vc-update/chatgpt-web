## 四大核心功能详解

### 1. 超长上下文：一次喂进整本书

Claude 常被用于长文档任务。实际可上传文件、上下文长度和代码库范围与账号、入口和当前限制有关，可以先从一份可复核的短文档测试：

- 总结要点、提炼结论；
- 跨章节/跨文件回答问题；
- 找出前后矛盾、遗漏的地方。

无论页面标注多长上下文，都要抽查原文位置、数字和跨章节结论，避免把“能读入”误解为“不会遗漏”。

### 2. 代码能力：开发者的主力助手

Claude 可用于代码解释、修改和测试，但输出必须在本地运行验证。常见用法：

- 写新功能、补全函数；
- 定位并修复 Bug，并解释原因；
- 重构老代码、加注释和单元测试；
- 解释陌生项目的整体结构。

建议把报错信息、相关代码片段一起贴给它，上下文越完整，结果越准。编程方向可延伸阅读 [ChatGPT Codex AI 编程教程](/chatgpt/chatgpt-codex-ai-biancheng-jiaocheng-2026)。

### 3. 中文写作：按读者与格式反复校对

Claude 可用于中文润色和改写。评价“自然”与否很主观，建议给出目标读者、语气、字数和禁止项，再检查事实与措辞。适合：

- 公众号、小红书、博客文案；
- 工作报告、邮件、周报；
- 长文初稿到精修。

### 4. 事实核验：任何模型都可能出错

Anthropic 公开强调安全研究，但这不代表回答天然正确。合同、论文、财务、医疗和企业材料仍要核对来源、权限和隐私，不能把模型语气克制当成事实保证。

## 实用 Prompt 技巧

想让 Claude 4.8 发挥到位，提问方式很关键：

1. **给角色和场景**：如"你是资深前端工程师，帮我 review 这段 React 代码"。
2. **说清输出格式**：要表格、要分点、要字数，直接讲明。
3. **一次给足上下文**：长文档、完整代码、背景信息一起给，别挤牙膏。
4. **分步迭代**：先出框架，再逐段细化，比一次性憋大招更稳。
5. **让它先想再答**：复杂问题加一句"先分析再给结论"，质量更高。
