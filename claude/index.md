## Claude 官方入口有哪些？

普通用户可以从 [claude.com](https://claude.com) 了解 Claude，登录入口常见为 [claude.ai](https://claude.ai)。桌面和移动端下载信息可看 Claude 下载页。开发者和 Claude Code 用户应优先阅读 Anthropic 官方文档。

中文搜索里的“Claude 中文版”“Claude 镜像站”多数不是 Anthropic 官方入口。它们可能是第三方平台、镜像站或教程站。

## 国内使用 Claude 的注意事项

1. 先确认官方入口和账号状态。
2. Claude Code 涉及本地文件和代码仓库，权限要谨慎。
3. 第三方中文平台不等于 Anthropic 官方。
4. 不要上传公司私有代码、密钥、合同和客户资料。
5. 注册、付费和订阅规则以页面实际展示为准。
