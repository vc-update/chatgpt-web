## Claude 是什么：来自 Anthropic 的对话模型

Claude 是 Anthropic 推出的大语言模型系列。Anthropic 由前 OpenAI 团队成员创立，主打"可靠、可控、安全"的 AI 路线，这也让 Claude 在长文档处理和严谨任务上口碑很好。

Claude 账号可能提供 Opus、Sonnet 或其他当前型号。具体命名和权限要看官方账号页面；第三方平台显示相同名称，也不代表与 Anthropic 官方账号、订阅或 API 完全一致。

可以把 Claude 用于以下任务，但每项都要结合当前账号权限与人工复核：

1. **长文档**：先用脱敏文件测试，再抽查引用、数字和遗漏。
2. **代码任务**：运行测试、审查依赖与权限，保留可回滚版本。
3. **中文写作**：指定读者、语气、字数与禁止项，再人工核对事实。
4. **正式材料**：不能因为语气克制就跳过来源、隐私和合规检查。
