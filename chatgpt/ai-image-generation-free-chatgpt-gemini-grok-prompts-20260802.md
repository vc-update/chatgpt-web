## AI图片提示词万能结构

把提示词写成给设计师的创作简报：

```text
用途 + 主体 + 构图 + 场景 + 光线 + 色彩 + 风格 + 文字 + 画幅 + 禁止项
```

### 商品主图提示词

```text
为一款白色便携咖啡机制作电商主图。商品位于画面中央，三分之二正面视角，
浅灰无缝背景，左上方柔光，材质真实，保留所有结构和按钮位置，
正方形构图，留出右侧文案空间。不要新增Logo、文字、配件或改变商品颜色。
```

### 中文海报提示词

```text
制作一张竖版夏季读书活动海报，画面主体是窗边书桌与绿色植物，
清爽蓝绿配色，顶部留出标题区域。标题只写“夏日阅读计划”，
下方小字只写“8月10日开始”，使用清晰无衬线中文字体，
不要增加其他文字、二维码或品牌标志。
```

### 人物一致性提示词

```text
保持参考图中成年男性的脸型、发型、眼镜、年龄和深蓝色衬衫不变，
将背景改为明亮办公室，人物坐在桌前查看笔记本电脑，半身中景，
自然窗光，真实摄影。不要改变五官，不要新增人物，不要出现多余手指。
```

### 插画提示词

```text
一名学生在夜晚图书馆整理学习笔记，桌上有书、本子和台灯，
俯视斜角构图，温暖灯光与深蓝背景形成对比，扁平杂志插画风格，
横版16:9，右侧留标题空间，不出现文字和Logo。
```

## 中文文字为什么容易出错

图像模型可能把文字视为图形纹理，因此出现错字、重复字和乱码。提高成功率的方法：

- 首轮只要求一行短文字。
- 用引号明确逐字内容。
- 指定文字位置、层级和简单字体。
- 不同时要求大量装饰字和复杂透视。
- 先生成无字背景，再在设计软件中添加可编辑文字。

正式商业海报更适合“AI 生成背景与构图 + 人工排版文字”的流程，这样便于校对和后续修改。

## AI图片生成失败怎么排查

| 问题 | 可能原因 | 处理方法 |
| --- | --- | --- |
| 不出图或直接拒绝 | 内容政策、服务或权限 | 改为合规原创需求，检查页面提示 |
| 一直加载 | 网络、服务高峰、任务复杂 | 保存提示词，用简单任务测试 |
| 人物不一致 | 参考图不足、改动过多 | 固定特征，一次只改一个变量 |
| 商品变形 | 风格化过强、视角变化太大 | 明确保留结构，减少镜头变化 |
| 中文乱码 | 文字过多、版式复杂 | 缩短文字，后期人工排版 |
| 图片模糊 | 输出尺寸、压缩或免费层限制 | 核对下载格式与当前计划 |
| 无法编辑上传图 | 格式、权限、文件或模式不支持 | 转换常见格式，用公开小图测试 |

## AI生成图片能不能商用

商用判断至少包括：

- 平台和当前计划是否允许对应用途。
- 上传的参考图、字体、Logo 和素材是否有授权。
- 是否包含真实人物、明星、角色或品牌资产。
- 图片是否容易误导用户相信某个事件真实发生。
- 客户或投放平台是否要求 AI 内容标注。

重要作品应保留素材来源、提示词、生成日期和人工修改记录。法律和平台政策会变化，重大商业用途应再做专业核验。

## FAQ

### AI图片生成免费工具哪个最好？

没有统一答案。插画、中文海报、商品图、人物一致性和局部编辑需要的能力不同，应使用同一任务实测再决定。

### AI图片生成需要下载软件吗？

很多服务提供网页版，也有应用或 API。使用前确认真实域名、服务主体、上传规则和下载格式，不要安装来源不明的软件包。

### ChatGPT、Gemini、Grok都能画图吗？

具体取决于当前产品、账号、模型和入口。看到某个品牌名称不代表所有入口都开放相同绘图能力，应以页面实际显示为准。

### AI绘图提示词越长越好吗？

不是。提示词应完整但可执行。主体、构图和修改要求明确，比堆叠大量风格和画质形容词更重要。

### AI图片可以去水印吗？

应使用平台提供的合规下载方式。不要通过来源不明工具移除版权、平台或内容凭证标识。

### SnakeGPT和GPTCat免费吗？

不免费。二者都是付费第三方多模型与绘图平台，模型、功能和额度以实际页面为准。
