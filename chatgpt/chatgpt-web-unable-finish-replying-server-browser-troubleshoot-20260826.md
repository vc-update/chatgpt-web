## 先给结论：先保存内容，再判断是不是全站故障

看到“无法完成回复”“Something went wrong”或服务器无响应时，第一动作不是连续刷新，而是：

1. 复制已经生成的文字、提示词和待办事项；
2. 记录错误出现的时间、是否带文件、使用的浏览器和对话长度；
3. 在新对话里发送一条简短、不带附件的测试消息；
4. 查看 [OpenAI Status](https://status.openai.com/) 是否有公开事件；
5. 用无痕窗口或另一浏览器做一次对照；
6. 最后再处理 Cookie、扩展、网络和登录会话。

如果只有一个长对话失败，不要立即认定账号被限制；如果所有设备和网络都失败，才更需要关注服务或网络链路。

## “无法完成回复”常见对应关系

| 现象 | 可能方向 | 建议测试 |
| --- | --- | --- |
| 新对话短句也失败 | 服务、网络或账号会话 | 状态页、无痕窗口、另一网络 |
| 只有长对话失败 | 上下文、附件或工具状态 | 保存摘要后新建对话 |
| 只有带文件的任务失败 | 文件格式、权限、会话或内容 | 不带附件测试，再用脱敏小文件 |
| 生成到一半中断 | 服务波动、连接、队列或页面资源 | 保存已有内容后继续生成 |
| 只有普通浏览器失败 | Cookie、扩展或缓存 | 无痕窗口和另一浏览器 |
| 反复跳回登录页 | 会话、登录方式或系统时间 | 手动核对域名并原方式重登 |

错误提示的英文措辞可能变化，判断重点是“什么任务失败、在哪个环境失败、能否稳定复现”。

## 长对话失败：先做摘要迁移

如果旧对话已经很长，或包含大量附件、代码和多轮工具结果，可以先建立一份摘要：

```text
请把当前任务整理成可迁移摘要，包含：目标、已完成事项、关键事实、未解决问题、文件名、约束、下一步和不要重复做的事情。不要省略代码接口和错误信息，但不要输出任何密码或API Key。
```

复制摘要到本地后，在新对话中只提交必要内容。这样做的目的不是“绕过限制”，而是减少旧页面继续渲染大量上下文的负担，并保留工作状态。

## 文件任务失败：把附件和文字分开测试

先发一条不带附件的短消息。如果短消息正常，再检查：

- 文件是否真的上传完成；
- 文件格式和名称是否异常；
- 当前会话是否已经过期；
- 文件是否包含敏感、受限或无法处理的内容；
- 是否在移动端浏览器中遇到下载或权限问题。

不要把同一份客户表格、合同或源码先后上传到多个未知平台。为了测试，优先创建一份只含公开或虚构数据的小文件。

## 浏览器、网络和会话排查

### 用无痕窗口做一次对照

无痕窗口可以帮助排除部分 Cookie、缓存和扩展影响，但不保证所有网络问题都消失。若无痕窗口正常，逐个检查翻译、广告拦截、脚本注入和隐私扩展。

### 确认网络是否只影响网页

公司网络、代理、安全 DNS 和防火墙可能只影响某些请求。换网络时不要同时换账号，保持变量尽量少，才能知道哪项改变产生了结果。

### 重新登录前先确认账号方式

手动打开 `chatgpt.com`，使用注册时的邮箱、Google 或 Apple 登录方式。不要因为历史记录暂时为空就连续注册新账号，可能只是登录方式不同。

## 真实场景案例：回答失败并不是账号问题

小赵在一个包含大量 PDF、代码和多轮工具结果的长对话中请求继续生成报告，页面显示无法完成回复。他先复制已经生成的部分和任务要求，在新对话里用摘要继续，短消息和简短报告都正常。后来在无痕窗口重新打开旧对话，发现普通浏览器的脚本扩展也在修改页面。

这个案例同时包含上下文和浏览器两个变量。先保存内容、再做单变量测试，比连续刷新或更换账号更容易定位原因。

## 错误与避坑清单

- 看到错误就连续刷新，导致未发送内容丢失；
- 没保存已有回答就直接关闭长对话；
- 只在一个浏览器反复测试，不做无痕窗口对照；
- 为了排错上传含个人信息、客户资料或密钥的文件；
- 把状态页正常当成自己的浏览器和账号一定正常；
- 连续创建新账号，混淆历史记录和订阅归属；
- 通过第三方页面提交密码、验证码或所谓修复授权。

## 常见问题

### 无法完成回复就是服务器故障吗？

不一定，还可能是长对话、附件、浏览器、网络或会话问题。

### 回复中断后能恢复原文吗？

先保存页面上已经显示的内容，再尝试继续生成或用摘要迁移；不要承诺一定能恢复未显示部分。

### 新对话正常说明什么？

通常说明旧对话上下文、附件或页面资源可能是变量之一。

### 无痕窗口正常怎么办？

逐个排查扩展、Cookie和缓存，保留能稳定复现的最小步骤。

### 文件导致回复失败怎么办？

先不带附件测试，再用脱敏小文件分步复现。

### 第三方平台能恢复官方回答吗？

不能。第三方服务不能读取或恢复官方账号中的未保存回答。
