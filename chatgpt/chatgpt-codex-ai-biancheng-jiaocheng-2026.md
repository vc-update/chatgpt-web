## 导读

Codex 把 ChatGPT 从"会聊代码"变成了"会干活"——它能读懂你的代码库、独立完成功能、修 bug、跑测试，像个真正的编程搭档。这篇教程讲清楚 Codex 是什么、能做什么、怎么用提示词把它的能力榨干，以及国内开发者怎么用上 Codex。

## Codex 是什么

Codex 是 OpenAI 面向编程场景的智能体能力。和你在对话框里贴一段代码问问题不同，Codex 更进一步：它能在理解整个项目结构的基础上，自主完成多步骤的开发任务。你给它一个需求，它会去定位相关文件、写代码、运行、根据结果迭代，最后把改动整理好给你。

底层由 GPT-5.5 这一代模型驱动，得益于这代模型在推理稳定性和长上下文上的提升，Codex 处理大型代码库、复杂逻辑时比早期可靠得多。

## Codex 能做什么

- **实现新功能**：描述需求，它从零写出可运行的代码。
- **修复 bug**：贴上报错或描述异常，它定位根因并给出修复。
- **重构与优化**：让它改善代码结构、提升性能、补充注释。
- **写测试**：为现有函数自动生成单元测试。
- **解释代码**：快速读懂陌生项目或他人的代码。
- **跨语言迁移**：把一种语言的实现翻译成另一种。

## 高效使用 Codex 的方法

### 1. 需求描述要具体

模糊的"帮我写个登录功能"和具体的需求差别巨大。好的描述包含：要实现什么、用什么技术栈、有哪些约束、期望的输入输出。

> 示例：用 Python FastAPI 实现一个邮箱+密码登录接口，密码用 bcrypt 加密存储，登录成功返回 JWT，处理邮箱不存在和密码错误两种异常，附单元测试。

### 2. 先思路后代码

让它"先说实现思路，我确认后再写代码"。复杂任务这一步能避免方向跑偏，省下大量返工。

### 3. 善用迭代

代码不对时，把报错原文和现象贴回去，让它基于真实反馈修，比你自己描述准得多。

### 4. 让它自检和处理边界

在需求里加上"考虑边界情况和异常处理""完成后自查潜在 bug"，配合 GPT-5.5 更强的自检能力，产出质量明显更高。

### 5. 安全意识

涉及鉴权、数据库、对外接口的代码，务必自己审一遍。AI 生成的代码可能有安全隐患（如 SQL 注入、硬编码密钥），不要不审就上线。
