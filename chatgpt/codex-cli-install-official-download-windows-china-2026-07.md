## 常见问题

### codex cli和codex安装是同一个意思吗？

不完全一样。codex cli通常是主搜索词，codex安装更接近具体入口或操作意图。写文章时把它们放在同一篇里，是为了覆盖用户从“找入口”到“怎么用”的完整路径。

### 为什么标题要同时出现多个关键词？

Bing 里很多用户不会只搜一个词，而会把官网、入口、网页版、中文版、国内使用、下载、登录等词混着搜。标题自然叠加这些词，可以更快覆盖长尾搜索意图。

### 可以把镜像站当官网吗？

不建议。镜像站、中文工具和教程站都要和 OpenAI 官方入口区分开，账号密码、付款、API Key 和敏感资料不要随便输入到不明页面。

### 新手应该先用网页版还是下载 App？

大多数新手可以先用网页版，因为免安装、容易排查问题，也更适合长文本办公。确认长期需求后，再考虑 App、桌面端或 API。

### 哪些信息不适合输入到第三方入口？

账号密码、验证码、API Key、合同、客户资料、身份证、未公开代码、生产配置和公司内部文件都不适合输入到不明入口。

### Codex 能直接改生产项目吗？

不建议。应先在测试分支或样例项目中使用，所有修改都要看 diff、跑测试，并人工确认安全边界。
