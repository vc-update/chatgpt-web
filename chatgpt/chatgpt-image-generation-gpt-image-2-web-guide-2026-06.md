## 适合网页端完成的任务

| 任务 | 适合程度 | 建议 |
| --- | --- | --- |
| 博客封面 | 高 | 16:9，留标题区 |
| 小红书封面 | 高 | 3:4 或 9:16，标题后期加 |
| PPT 配图 | 高 | 不要让 AI 写太多字 |
| 电商主图 | 中 | 注意产品真实性 |
| Logo 设计 | 中 | 只能做灵感，不能直接商用 |
| 证件照 | 低 | 涉及真实身份和平台规范 |

## 网页端使用流程

1. 打开 ChatGPT 官方入口。
2. 选择支持图片生成的模型或功能。
3. 输入结构化提示词。
4. 查看结果并继续要求修改。
5. 下载图片，必要时用设计工具加文字。

具体功能是否显示，要以你的 ChatGPT 账号和官方页面为准。

## 推荐提示词模板

```text
请生成一张 16:9 博客封面图。
主题：ChatGPT 图片生成教程 2026。
画面：电脑屏幕、AI 对话界面、图片生成元素、中文教程氛围。
风格：现代科技感，明亮，干净，适合网站首页。
构图：左侧留出标题区域，右侧放视觉主体。
要求：不要生成真实品牌 logo，不要生成乱码中文。
```

## 中文海报怎么写？

```text
生成一张中文活动海报。
主标题：AI 图片生成公开课
副标题：从提示词到商业素材
风格：科技感、明亮、清爽。
构图：标题大，视觉主体清晰，底部留信息区。
比例：9:16。
要求：文字清晰，不要乱码，不要水印。
```

如果多次出现乱码，可以改成：

```text
请生成无文字海报背景，上方和下方留出文字区域，我会后期自己加中文。
```

## 多轮修改怎么说？

不要重新写一大段 prompt，直接说保留和修改：

```text
保留整体构图和颜色。
把背景改得更干净。
减少屏幕上的文字。
右侧加入更明显的图片生成图标。
不要改变 16:9 比例。
```

## 国内用户注意事项

1. 不要把第三方中文站当成 OpenAI 官方官网。
2. 不要上传身份证、合同、客户图片等敏感素材。
3. 不要输入账号密码到不明镜像页。
4. 商业图片要检查版权、商标和肖像风险。
5. 免费工具如果要求 API Key，要谨慎。

## 中文图片提示词模板

可以直接按这个格式写：

> 生成一张 16:9 横版中文科技海报，主题是“ChatGPT 国内使用指南”，画面包含浏览器窗口、对话气泡、官网入口和安全盾牌元素，整体干净、现代、信息层级清楚。主标题不超过 12 个中文字符，副标题不超过 18 个中文字符，避免乱码，留出顶部标题区和底部说明区。

## 追加 FAQ：GPT-Image-2 搜索用户常问

### GPT-Image-2 和 ChatGPT Images 2.0 是一回事吗？

可以把它理解为同一类图片生成能力在不同场景下的叫法：普通用户关心 ChatGPT 里的图片生成入口，开发者更关心 OpenAI API、模型名称、参数和调用方式。

### GPT-Image-2 适合做中文海报吗？

适合，但提示词要控制文字长度。中文标题越短越稳，最好明确“主标题不超过多少字”“副标题不超过多少字”“不要出现乱码”，生成后再用多轮修改微调。

### 第三方在线生图站可以直接填 API Key 吗？

不建议。API Key 等同于账号权限，不要填到来路不明的网站。需要 API 调用时，优先看官方文档，或使用可信平台并单独控制额度和权限。

## FAQ

### ChatGPT 网页版可以生成图片吗？

是否可用取决于账号、模型和官方当前开放情况。你应以 ChatGPT 页面实际显示为准。

### GPT-Image-2 网页版在哪里？

普通用户通常从 ChatGPT 图片功能使用；开发者从 OpenAI API 文档接入。不要把第三方页面直接当成官方网页版。

### 中文海报为什么容易乱码？

图片模型生成文字仍可能出错。复杂中文建议先生成无文字背景，再用设计工具加字。
